<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Detectly/raw/main/favicon_io/favicon.ico" width="35"/> Detectly</h1>

<p align="center">
  ウェブカメラを使用して、顔、手、ポーズ、ジェスチャー、物体をリアルタイムで検出するコンピュータビジョンアプリケーションです。
</p>

## <img src="https://github.com/KrishBharadwaj5678/Detectly/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ------------------------- | ------------------------------------------------ |
| 👤 顔検出 | 顔をリアルタイムで検出・追跡 |
| 🧍 姿勢推定 | 身体の動きやポーズを検出・追跡 |
| ✋ ハンドトラッキング | 手の位置や動きを正確に追跡 |
| ✨ ジェスチャー認識 | 手のジェスチャーや動きをリアルタイムで認識 |
| 📦 物体検出 | ウェブカメラを通して物体を検出・識別 |
| 🖼️ スクリーンショット保存 | 現在のウェブカメラ映像をキャプチャしてダウンロード |
| 📱 レスポンシブデザイン | デスクトップとモバイル端末の両方で快適に動作 |

## <img src="https://github.com/KrishBharadwaj5678/Detectly/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Detectly.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Detectly
```

### 3️⃣ ブラウザで開く

`index.html` ファイルをブラウザで開くだけで利用できます。
