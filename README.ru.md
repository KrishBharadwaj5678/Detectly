<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Detectly/raw/main/favicon_io/favicon.ico" width="35"/> Detectly</h1>

<p align="center">
  Приложение компьютерного зрения в реальном времени, которое обнаруживает лица, руки, позы, жесты и объекты непосредственно через веб-камеру.

## <img src="https://github.com/KrishBharadwaj5678/Detectly/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ------------------------- | ------------------------------------------------ |
| 👤 Распознавание лиц | Обнаружение и отслеживание лиц в реальном времени |
| 🧍 Определение позы тела | Определение и отслеживание движений и поз тела |
| ✋ Отслеживание рук | Точное отслеживание положения и движений рук |
| ✨ Распознавание жестов | Распознавание жестов и движений рук в реальном времени |
| 📦 Обнаружение объектов | Обнаружение и идентификация объектов через веб-камеру |
| 🖼️ Сохранение скриншотов | Создание и загрузка снимка текущего кадра с веб-камеры |
| 📱 Адаптивный дизайн | Плавная работа на компьютерах и мобильных устройствах |
